## Como usar a tabela

- **Login e senha validados:** pode utilizar o e-mail e a senha apresentados para entrar.
- **Não localizada:** a conta existe, mas sua senha atual não está disponível nos registros locais. O Firebase não permite consultar a senha existente; para estabelecer uma senha conhecida, é necessário redefini-la.
- **Não definida:** o usuário possui somente cadastro interno. É necessário provisionar sua conta no Firebase e vinculá-la ao cadastro para permitir login.
- Não foi confirmada uma senha padrão única para todos os usuários.
